# 若初的神秘插件

多功能 AstrBot 插件，集成 **RailGo 铁路信息查询** 与 **UAPI 全能接口**，共 44+ 个实用指令，铁路查询结果以精美图片形式呈现。

---

## 若初的神秘插件

数据来源：RailGo API

| 指令 | 说明 | 示例 |
|------|------|------|
| /车次查询 | 查询列车完整信息，含车次主数据、检票口/站台、时刻表、各站正晚点 | /车次查询 G1 |
| /区间查询 | 查询车次在某区间内的停靠站、正晚点，检票口按区间起点站显示 | /区间查询 G1 北京南 南京南 |
| /站到站 | 查询两站之间当日开行的所有列车列表 | /站到站 北京南 上海 20251009 |
| /车站查询 | 查询车站详细信息及途经所有列车 | /车站查询 新余北 |
| /随机选取车次 | 随机获取一趟列车信息 | /随机选取车次 |
| /车次正晚点 | 查询列车各站正晚点情况 | /车次正晚点 G1 |

## UAPI 通用接口

数据来源：UAPI

### 天气类

| 指令 | 说明 | 示例 |
|------|------|------|
| /天气 | 实时天气 + 7 天预报 + 生活指数 | /天气 北京 |

| /世界时间 | 查询世界各城市当前时间 | /世界时间 Tokyo |
